### 数据模型
```typescript
interface Workspace {
  id: string
  name: string
  folderPath: string
  createdAt: Date
  lastAccessed: Date
}
```

### 核心功能
1. **工作区管理**: 支持多工作区创建、切换、管理
2. **文件夹持久化**: 完整的文件夹结构和内容持久化
3. **拖拽导入**: 支持拖拽文件夹进行批量导入
4. **树形展示**: 递归展示文件夹结构和文件列表

### 组件架构
- `WorkspaceSelector.vue`: 工作区选择和管理
- `FolderTree.vue`: 文件夹树形展示主组件
- `FolderTreeNode.vue`: 单个树节点递归组件
- `HomePage.vue`: 主页面集成所有功能
